<h2>This is an addon for Blender (tested on Blender 5.x) to visualize the center of mass of a given mesh.</h2>


<h2>SLOP WARNING</h2>
This project was entirely vibe coded with Claude Opus 5.5 Extra effort, some or all of the results it gives may be partially or completely inaccurate.
With that said, I do use this addon myself and it seems to be accurate enough for my purposes.

<h3>Features:</h3>
- Visualize center of mass for a given mesh object
- Apply different materials to the mesh (mainly plastics used in 3D printing)
- Adjust simulated infill value of the mesh
- Calculate the angle at which the object would tip over at
